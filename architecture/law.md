# 法律业务系统分类体系

  ## 0. 使用目标与落库规范（MVP）

  本文档用于定义 **LawSeekDog 的“业务分类字典”**（可落库、可版本化、可映射到国家/行业标准口径），主要服务于：

  - 事项/案件（matter）创建时的分类选择与统计口径统一
  - 模板/文书/知识库的检索维度（按业务类型/争议类型/程序阶段等过滤）
  - 运营报表（业务结构、来源、转化、费用、胜诉率等）的维度标准化

  ### 0.1 字典建模建议（统一字典表）

  为避免每个字典建一张表带来的维护成本，建议使用“统一字典表”承载所有分类项：

  | 字段 | 类型 | 说明 |
  |------|------|------|
  | dict_key | varchar | 字典标识，如 `business_type` / `litigation_domain` / `civil_cause_group` |
  | code | varchar | **稳定编码**（业务侧主键），全局唯一（建议 `dict_key + code` 唯一） |
  | name | varchar | 名称（展示用） |
  | parent_code | varchar | 上级编码（同 dict_key 内） |
  | level | int | 层级（从 1 开始） |
  | sort | int | 排序（越小越靠前） |
  | aliases | text | 同义词/别名（逗号分隔） |
  | keywords | text | 检索关键词（逗号分隔） |
  | description | text | 边界说明（包含/不包含/典型例子） |
  | source_system | varchar | 外部标准来源（可选），如 `spc_civil_cause_2020` / `prc_criminal_law` |
  | source_ref | varchar | 外部标准引用（可选），如 `法〔2020〕347号` |
  | source_code | varchar | 外部标准编码（可选；若无官方编码则留空） |
  | is_active | bool | 是否启用（下架不删除，便于历史兼容） |
  | version | varchar | 字典版本（如 `2026.02`） |

  > 若你更偏向“每个字典单表”，也可以保持 `dict_business_type` 等分表形式，但字段至少应包含：`code/name/parent_code/level/sort/is_active/version/source_*`。

  ### 0.2 编码规范（必须）

  - 编码建议使用大写分段：`SEGMENT.SEGMENT[.SEGMENT...]`（仅包含 A-Z/0-9/下划线），例如：`BT.LIT`、`LIT.CIV`、`CIV.CONTRACT.SALE`。
  - 编码一经发布不得复用/改义；如需调整含义，应新建 code，旧 code 下线（`is_active=false`）但保留。
  - **维度拆分原则**：不要把“争议类型（案由/罪名）”“程序阶段（立案/一审/执行）”“服务产品（尽调/培训）”混在同一棵树里；应使用不同 `dict_key`，并在业务表里用不同字段承载。

  ### 0.3 标准映射（建议）

  - 民事争议大类建议对齐《民事案件案由规定》（法〔2020〕347号）的 11 大类口径（见附录 13.1）。
  - 刑事案件类型建议对齐《刑法》罪名分组的 10 大类口径（见附录 13.2）。
  - 映射做法：在字典项上补 `source_system/source_ref/source_code/source_name(可由 description 承载)`；若无官方编码，至少要有“标准名称”一致的映射。

  ## 一、业务类型总览

  法律业务体系
  ├── 1. 诉讼业务（Litigation）
  ├── 2. 仲裁业务（Arbitration）
  ├── 3. 非诉业务（Non-litigation）
  ├── 4. 法律顾问（Legal Counsel）
  ├── 5. 法律援助（Legal Aid）
  └── 6. 公证/调解/其他（Notarization/Mediation/Others）

  对应字典：`dict_key=business_type`

  | code | 名称 | 英文 | 说明 |
  |------|------|------|------|
  | BT.LIT | 诉讼业务 | Litigation | 以法院诉讼/执行为核心的争议解决 |
  | BT.ARB | 仲裁业务 | Arbitration | 以仲裁机构仲裁为核心的争议解决（含国内/国际） |
  | BT.NL | 非诉业务 | Non-litigation | 以交易/合规/尽调/投融资等非争议服务为主 |
  | BT.COUNSEL | 法律顾问 | Legal Counsel | 常年/专项顾问服务产品线 |
  | BT.AID | 法律援助 | Legal Aid | 面向受援对象的援助案件/事项 |
  | BT.OTHER | 公证/调解/其他 | Notarization/Mediation/Others | 公证、调解及其他法律服务 |

  ## 十三、附录

  ### 13.1 民事案由参考（部分）

  根据《最高人民法院关于印发修改后的〈民事案件案由规定〉的通知》（法〔2020〕347号），民事案由共分为十一大类：

  1. 人格权纠纷
  2. 婚姻家庭纠纷
  3. 继承纠纷
  4. 物权纠纷
  5. 合同纠纷
  6. 准合同纠纷
  7. 劳动争议、人事争议
  8. 知识产权与竞争纠纷
  9. 海事海商纠纷
  10. 与公司、证券、保险、票据等有关的民事纠纷
  11. 侵权责任纠纷

  ### 13.2 刑法罪名参考（部分）

  根据《中华人民共和国刑法》，罪名分为十类：

  1. 危害国家安全罪
  2. 危害公共安全罪
  3. 破坏社会主义市场经济秩序罪
  4. 侵犯公民人身权利、民主权利罪
  5. 侵犯财产罪
  6. 妨害社会管理秩序罪
  7. 危害国防利益罪
  8. 贪污贿赂罪
  9. 渎职罪
  10. 军人违反职责罪

  ### 13.3 行政处罚类型

  根据《中华人民共和国行政处罚法》：
