# LawSeekDog 文档站

本仓库维护 LawSeekDog 当前架构、Owner 边界、DSH/Tool 契约、业务流程和交付规范。入口是 [`index.md`](index.md) 与 [`architecture/project-map.md`](architecture/project-map.md)。

当前技术基线：React + TypeScript + Vite 前端；官方 DSH 与 `ai-engine-v2` profile；Java Owner 服务；PostgreSQL、对象存储和搜索服务。`ai-engine`、Vue、consultations-service 等旧方案仅可在历史迁移文档中引用。

修改文档时请区分“当前实现”和“规划”，并以目标仓库代码与契约为证据。不存在的页面不要加入导航链接。
